Criando um Website no Amazon S3

Lab 170 - Hospedagem de site estático utilizando Amazon S3 e AWS CLI

Neste laboratório, pratiquei a criação de um bucket S3, a configuração da hospedagem de site estático e a publicação de arquivos utilizando o AWS CLI. Também desenvolvi um script Bash para facilitar as atualizações.

Atividades realizadas

01

Amazon S3

Criação de bucket e configuração de recursos para armazenamento dos arquivos do website.

02

Permissões

Configuração de acesso público e habilitação de ACLs para os objetos do bucket.

03

Website estático

Habilitação da hospedagem estática e publicação dos arquivos HTML, CSS e imagens.

04

AWS CLI e Bash

Utilização de comandos AWS CLI e criação de script para automatizar o envio de atualizações.

O que aprendi

  • Criar e configurar buckets no Amazon S3 usando AWS CLI.
  • Configurar permissões para acesso público aos arquivos.
  • Habilitar hospedagem de websites estáticos no S3.
  • Publicar e atualizar arquivos de um website com comandos AWS CLI.
  • Automatizar tarefas de atualização utilizando scripts Bash.
